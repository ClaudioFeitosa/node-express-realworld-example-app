# Phase 01 - Discovery

Read:

* .ai/project-plan.md

Use the available repository analysis, architecture analysis, API discovery, and documentation skills.

Objectives:

* Understand the current repository.
* Identify technologies and dependencies.
* Analyze the current architecture.
* Map business functionality.
* Discover and document APIs.
* Identify technical debt and risks.
* Establish a baseline for future modernization activities.

Requirements:

* Use repository evidence only.
* Do not make assumptions.
* Mark unknown information as "Not Identified".
* Reference source files whenever possible.
* Generate production-ready documentation.
* Store all outputs under the docs directory.

Generate:

* docs/README.md
* docs/01-discovery/README.md
* docs/01-discovery/AS-IS.md
* docs/01-discovery/ARCHITECTURE.md
* docs/01-discovery/API-CONTRACT.md

Discovery Expectations:

AS-IS.md

* System overview
* Functional scope
* User journeys
* Technology stack
* Repository structure
* Technical debt
* Risks

ARCHITECTURE.md

* Architecture style
* High-level components
* Request lifecycle
* Dependency analysis
* Architectural concerns
* Modernization opportunities

API-CONTRACT.md

* Complete API inventory
* Authentication requirements
* Request parameters
* Request bodies
* Responses
* Error responses
* Source references

README.md

* Discovery summary
* Scope
* Findings
* Risks
* Generated artifacts
* Recommended next actions

Validation:

* Verify all major repository areas were analyzed.
* Verify all discoverable APIs were documented.
* Verify findings are supported by repository evidence.
* Verify outputs are complete and commit-ready.

At the end provide:

* Discovery summary
* Technology summary
* Architecture summary
* API inventory summary
* Technical debt summary
* Risks identified
* Recommended next actions
